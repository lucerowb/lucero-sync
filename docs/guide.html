Set up Lucero Sync

Install the app on two or more devices, pair them once, and then share files or back up your photos whenever they're on the same Wi-Fi.

Before you start

  • You need two or more devices: any mix of iPhone or iPad (iOS 15+), Android (7+), Mac (macOS 12+), Windows 10/11 or Linux.
  • They must be on the same network while transferring. Home Wi-Fi is ideal; guest networks often block devices from reaching each other.
  • Downloads are on the latest release. Only download from there.

Install on Android

  1. On the phone, download lucero-sync.apk and open it. If asked, allow Install unknown apps for your browser, then tap Install.
  2. Open Lucero Sync. Under Settings › Storage, tap Grant and switch on All files access. This saves backups to Pictures/LuceroSync and received files to Download/LuceroSync, where your gallery and file manager can see them.
  3. Go to Settings › Apps › Lucero Sync › Battery and choose Unrestricted, so Android doesn't pause long transfers.

Install on iPhone & iPad

Apple only lets you install apps from the App Store or apps signed with your own Apple ID. Pick one of these options.

Option A: AltStore or SideStore (recommended)

  1. Set up AltStore Classic or SideStore by following their instructions.
  2. In AltStore or SideStore, open Sources, tap +, and add: 
    https://github.com/lucerowb/lucero-sync/releases/latest/download/altstore-source.json
  3. Install Lucero Sync from that source. New versions show up there as updates.

Option B: Build it with your free Apple ID

  1. On a Mac, install Xcode, Flutter and CocoaPods, then: 
    git clone https://github.com/lucerowb/lucero-sync.git
cd lucero-sync && flutter pub get
cp ios/Flutter/Signing.example.xcconfig ios/Flutter/Signing.local.xcconfig
    Open Signing.local.xcconfig and set your Team ID (shown in Xcode › Settings › Accounts) and a unique bundle ID.
  2. On the iPhone, switch on Settings › Privacy & Security › Developer Mode and restart.
  3. Connect the iPhone, then run flutter run --release. On first launch, trust your Apple ID under Settings › General › VPN & Device Management.
7-day limit

Apps signed with a free Apple ID stop opening after 7 days. AltStore and SideStore refresh them automatically in the background; with option B, run flutter run --release again. Your pairings and history are kept.

Install on macOS

  1. Download lucero-sync-macos.zip, unzip it, and drag Lucero Sync into Applications.
  2. The first time, right-click the app › Open, then click Open. This is needed once because the app isn't notarised by Apple yet. If macOS still refuses, go to System Settings › Privacy & Security and click Open Anyway.
  3. Allow Local Network access when asked. Allow Photos access too if you want to back up your Mac's photo library.

Install on Windows

  1. Download lucero-sync-windows-x64.zip and extract it to a folder, for example C:\Users\you\Apps\Lucero Sync.
  2. Run lucero_sync.exe. If SmartScreen appears, click More info › Run anyway; the app isn't signed with a paid certificate yet.
  3. When Windows Firewall asks, allow access on Private networks. Make sure your Wi-Fi is set to Private under Settings › Network & internet; on "Public" networks other devices can't find your PC.

Install on Linux

  1. Install the runtime dependencies. On Debian or Ubuntu: 
    sudo apt install libgtk-3-0 zenity
  2. Download lucero-sync-linux-x64.tar.gz, extract it and run the installer. It installs for your user only, with no root needed, and adds a menu entry: 
    mkdir lucero-sync && tar -xzf lucero-sync-linux-x64.tar.gz -C lucero-sync
cd lucero-sync && ./install.sh
  3. If you use a firewall, allow TCP port 8765 and mDNS, for example sudo ufw allow 8765/tcp and sudo ufw allow 5353/udp.

Pair your devices

Pair each pair of devices once. Pairing is mutual: afterwards either device can send to the other.

Nearby devices (easiest)

  1. Open Lucero Sync on both devices. Each one appears on the other's Share screen as Nearby · not paired.
  2. Tap Pair. Both screens show the same six-digit code.
  3. If the codes match, tap Accept on the device that received the request and Codes match on the one you started from.
Codes must match

The code is how Lucero Sync knows nobody is intercepting the connection. If the two codes differ, tap Codes don't match on either device and try again on a network you trust.

QR code

On the device you want to pair with, tap the QR button next to its name (or Add device › Show my pairing code). On a phone or Mac, choose Add device › Scan QR code. No code comparison is needed: the QR code already proves which device it is. Each code works once and expires after 10 minutes.

By IP address

If discovery is blocked on your network, use Add device › Enter IP address with the address shown under Settings › Connection help on the other device, then compare the codes as above.

Send files & text

  1. On Share, choose Files or Photos & videos. On a computer you can also drag files onto the window.
  2. Tap the device to send to. It shows what's coming (names, sizes and total) with Accept and Decline buttons.
  3. Progress appears on Share and in Activity. If the connection drops, the transfer resumes where it stopped.

Text and links: tap ⋮ on a device and choose Send text. The other device shows it with Copy and Open link buttons.

Skip the confirmation: tap ⋮ › Accept files automatically, or tick Always accept from… on an incoming request. Do this only for your own devices.

Share from other apps

In Photos, Files, a browser or any other app, tap Share and choose Lucero Sync. Lucero Sync opens with the items ready; tap the device to send them to. On iPhone, if Lucero Sync isn't in the first row, tap More and add it to your favourites.

Progress, Dynamic Island & tray

  • Both devices show every transfer under In progress (on Share, Backup and Activity), including photo backups another device is sending to this one. A transfer that stops arriving shows as paused.
  • iPhone (iOS 16.2+): progress appears in the Dynamic Island and on the Lock Screen while you use other apps. Touch and hold the island for details. You can turn this off under Settings › Lucero Sync › Live Activities.
  • Mac, Windows, Linux: the star icon in the menu bar or system tray shows progress (on a Mac, as a percentage next to the icon) and has Send files to and Send clipboard to menus. Closing the window keeps Lucero Sync receiving; use Quit in that menu to exit. On GNOME, the icon needs the AppIndicator extension (Ubuntu has it on by default).

Web access

Use any computer or phone on the same Wi-Fi without installing anything:

  1. On a device running Lucero Sync, open Settings › Web access and turn it on.
  2. On the other computer, open one of the https://… addresses it shows. The browser warns that the connection isn't private because the device uses its own certificate. To be sure it's your device, compare the certificate's SHA-256 fingerprint with the one shown under Web access, then continue.
  3. Enter the 6-digit code. You can now drop files to send them, send text, and download anything you add under Send to browser.

Web access stays on until you turn it off or close the app, and turning it off signs every browser out.

Browser extension

Send links, images, selected text and whole pages from Chrome, Edge, Brave or Firefox to any paired device. It needs Lucero Sync running on the same computer.

  1. Download lucero-sync-chrome.zip or lucero-sync-firefox.zip from the latest release and unzip it.
  2. Chrome, Edge, Brave: open chrome://extensions, turn on Developer mode, click Load unpacked and choose the folder. Firefox: open about:debugging › This Firefox › Load Temporary Add-on and pick manifest.json (temporary add-ons are removed when Firefox restarts).
  3. In Lucero Sync, open Settings › Browser extension › Connect a browser and enter the code in the extension's popup.

Then right-click anything on a page and choose Send to Lucero Sync device, or use the toolbar button.

Back up photos

You can back up the photo library of an iPhone, iPad, Android phone or Mac to any paired device. A Windows or Linux computer makes a good backup destination.

  1. Open Backup and choose the device under Back up to.
  2. Tap Back up now. Allow Full Access to Photos when asked; "Limited" only backs up the photos you select.
  3. Keep the app open (on iPhone, plug it in for big libraries). Later backups only send photos taken since the last one.

Turn off Include videos to back up photos only. Live Photos always include their motion clip. If you use iCloud's Optimize iPhone Storage, the phone downloads originals from iCloud as it goes, so it needs internet access too.

iPhone / iPadFiles › On My iPhone › Lucero Sync › Backups… › Lucero Sync › Received
Mac, Windows, Linux~/Pictures/Lucero Sync/YYYY/MM~/Downloads/Lucero Sync

Change either folder under Settings › Storage on every platform except iOS. Existing files are never overwritten; if a name already exists, the new file gets a number, as in IMG_0001 (1).HEIC.

iPhone & iPad as receiver

Files received on iOS live inside the app, and iOS deletes them if you uninstall Lucero Sync. Move them out with the Files app, or use Activity › Share or save, before uninstalling.

Upgrading from 0.1

Version 0.2 replaces the old connection protocol with an encrypted one. After updating all your devices, pair them again. Your backup history is kept, so photos that were already backed up aren't sent again.

Troubleshooting

ProblemFix
Devices don't see each otherBoth need Lucero Sync open with Receiving on, on the same network. Guest Wi-Fi, "client isolation", VPNs and Windows "Public" networks block this. Pair by QR or IP address instead (Settings › Connection help).
"Couldn't verify the other device's identity"The other device presented a different key than the one you paired with. This is normal if it was reinstalled: remove it and pair again. Otherwise, someone may be impersonating it.
Device shows "Identity changed"Same as above. It won't be trusted until you remove it and pair again.
"No longer recognises this one"The other device removed this pairing. Pair again.
Backup, photo picking or QR scanning doesn't workOpen Settings › Permissions. It shows what's allowed and has a button to fix each one.
Nothing happens on iPhoneAllow Settings › Privacy & Security › Local Network › Lucero Sync.
Mac says the app can't be openedRight-click › Open, or System Settings › Privacy & Security › Open Anyway.
Linux file picker doesn't openInstall zenity (GNOME) or kdialog (KDE).
Some backup items failedUsually iCloud originals that couldn't be downloaded. Connect to the internet and tap Retry failed.
The iPhone app won't open after a weekThe free signing expired. Refresh it in AltStore or SideStore, or reinstall it.

Still stuck? Open an issue and include the log from Settings › Connection help.

Removing & resetting

  • Remove a device: tap ⋮ on it, or go to Settings › Paired devices. Neither side can then send to the other until you pair again.
  • Rename this device: Settings › This device.
  • Reinstalling creates a new device identity, so you'll need to pair it again. Backup destinations still recognise files they already have, so nothing is duplicated.
  • Deleting photos on your phone never deletes them from the backup.
