# Lucero Sync browser extension

Send links, images, text and whole pages from Chrome or Firefox to your own phones, tablets and computers over local Wi-Fi. Nothing goes through a cloud.

The extension doesn't talk to your other devices itself. It talks to the **Lucero Sync desktop app** running on the same computer, through a small HTTP API that only listens on `127.0.0.1`. The desktop app then sends things to your paired devices over its encrypted protocol.

## What it does

- **Right-click menu → "Send to Lucero Sync device"** with one entry per paired device:
  - on a page: sends the page title and URL
  - on a link: sends the link URL
  - on selected text: sends the text
  - on an image: downloads the image and sends it as a file (or sends the image URL if it can't be downloaded)
- **Toolbar popup:**
  - your paired devices, with online status. Click one to send the current tab.
  - a text box to send any text
  - **Choose files** to send files from this computer
  - an **In progress** list with live transfer progress
- A notification tells you when something was sent, or why it couldn't be.

## Install

Download `lucero-sync-chrome.zip` or `lucero-sync-firefox.zip` from the [releases page](https://github.com/lucerowb/lucero-sync/releases).

**Chrome, Edge, Brave and other Chromium browsers**

1. Unzip `lucero-sync-chrome.zip` into a folder you'll keep.
2. Open `chrome://extensions` and turn on **Developer mode** (top right).
3. Click **Load unpacked** and choose the unzipped folder.

**Firefox 115 or later**

- If a signed `.xpi` is published with the release, open it in Firefox to install it permanently.
- Otherwise, open `about:debugging` → **This Firefox** → **Load Temporary Add-on…** and pick `lucero-sync-firefox.zip` (or the `manifest.json` inside it once unzipped). Temporary add-ons are removed when Firefox restarts.

## Connect it to the desktop app

1. Open Lucero Sync on this computer and go to **Settings › Browser extension**. The app shows a 6-digit code.
2. Click the Lucero Sync icon in your browser toolbar and enter the code.

That's it. The extension keeps a token in browser storage so you only do this once. Use **Disconnect** at the bottom of the popup to forget it. You can also revoke it from the desktop app.

If the popup says **Open Lucero Sync on this computer**, the desktop app isn't running. Open it and click **Retry**. The extension looks for the app on ports 47865–47869.

### Sending images as files

Downloading an image from a website needs permission to access that site. The first time you send an image, the browser asks whether Lucero Sync may download images from any site. You can also grant this with **Allow** in the popup. If you say no, images are sent as links.

## Privacy

- The extension talks only to the Lucero Sync app on `http://127.0.0.1` (your own computer). The one exception is downloading an image you chose to send from the right-click menu. That request goes to the site the image came from, as if you'd saved it.
- No analytics, no tracking, no remote code, no accounts.
- Stored locally in the browser: the app's port, the connection token, and the cached list of your device names.

## Build from source

No npm and no bundler. It's plain JavaScript.

```bash
./build.sh            # writes dist/lucero-sync-chrome.zip and dist/lucero-sync-firefox.zip
```

`build.sh` needs only `bash` and `zip` (macOS or Linux). To try your changes without zipping, build once, unzip `dist/lucero-sync-chrome.zip` and load that folder unpacked. Or copy `src/` somewhere, rename the right `manifest.*.json` to `manifest.json`, and load that.

Icons are generated by `python3 tools/make_icons.py`, which uses only the Python standard library.

### Layout

| Path | Purpose |
| --- | --- |
| `src/manifest.chrome.json` / `src/manifest.firefox.json` | Manifest V3 for each browser (copied in as `manifest.json` at build time) |
| `src/lib.js` | Loopback API client: port discovery, auth, endpoints, error text |
| `src/background.js` | Context menus, image download, notifications |
| `src/popup.html`, `popup.css`, `popup.js` | Toolbar popup |
| `src/icons/` | Generated PNG icons |
| `tools/make_icons.py` | Icon generator |
